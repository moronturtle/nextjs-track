# Demo SPA — React murni (CSR)

React SPA sengaja dibuat polos untuk perbandingan dengan `starter/` (Next.js).

Eksperimen yang disarankan (lihat [README pertemuan](../README.md)):

1. Klik kanan preview → **View Page Source** → HTML-nya kosong, cuma `<div id="root">`.
2. Matikan JavaScript di DevTools → reload → halaman kosong total.
3. Klik tombol Beranda/Tentang → "pindah halaman" tanpa reload, URL tidak berubah.

Bandingkan dengan `starter/` Next.js: view source-nya berisi konten, dan tetap tampil walau JS dimatikan.
