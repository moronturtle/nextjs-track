# Contributing

Repo ini adalah materi kursus — kontribusi paling berharga adalah laporan masalah.

## Lapor typo atau materi yang keliru

1. Buka tab **Issues** di repo ini.
2. Klik **New issue**, pakai format judul: `[nomor-pertemuan] deskripsi singkat`
   - contoh: `[01-pengenalan] typo di bagian struktur folder`
   - contoh: `[02-setup] perintah create-next-app error di StackBlitz`
3. Di isi issue, sertakan:
   - link ke file/bagian yang bermasalah
   - apa yang kamu lihat vs apa yang seharusnya
   - screenshot kalau perlu

## Usul materi atau latihan

Buka issue dengan label `usulan` — jelaskan topiknya dan kenapa menurutmu penting buat peserta.

## Pertanyaan soal materi

Jangan lewat issue kalau cuma tanya materi — pakai forum/grup kursus yang sudah disediakan mentor. Issue khusus untuk masalah di repo ini (typo, link mati, kode error, instruksi ambigu).
