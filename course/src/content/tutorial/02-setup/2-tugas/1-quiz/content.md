# Quiz — cek pemahamanmu

Ada **6 soal pilihan ganda** tentang setup project, package manager, ESLint, Prettier, type check, Tailwind CSS, dan router Next.js. Kerjakan di panel Preview.

- Pilih satu jawaban untuk setiap soal.
- Jawaban langsung dinilai. Jika jawabanmu belum tepat, quiz menunjukkan jawaban yang benar dan alasannya.
- Setelah soal terakhir, kamu bisa melihat skor dan mengulang quiz.

Quiz ini adalah latihan mandiri. Setelah selesai, buka tugas dan lanjutkan project yang kamu buat pada pertemuan 01.
