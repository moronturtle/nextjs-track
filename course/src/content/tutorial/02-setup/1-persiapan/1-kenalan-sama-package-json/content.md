# Kenalan sama `package.json`

Ingat pertemuan 01: `package.json` itu "daftar belanja" project — sekarang kita bedah isinya.

Buka `package.json` di editor. Perhatikan tiga bagian:

- **`scripts`** — perintah yang bisa dijalankan: `npm run dev`, `npm run build`, dst.
- **`dependencies`** — library yang dipakai saat app jalan (next, react).
- **`devDependencies`** — alat bantu saat develop saja (typescript, eslint, tailwind).

> Materi lengkap pertemuan ini masih disusun — ini contoh lesson untuk melihat navigasi antar-pertemuan.
